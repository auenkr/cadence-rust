## Real failures

**R1. Cassandra domain metadata type check (affects every Rust service on Cassandra: matching, frontend, history gates).**
Rust startup dies with `Go Cassandra domain metadata error: Type check failed ... against CQL column types`. The CI schema has `domain_config.bad_binaries_encoding` as `Blob`, but the Rust `CassandraDomainConfigUdt.bad_binaries_encoding` is `Option<String>` (CQL text): `rust/crates/cadence-persistence/src/cassandra.rs:136`. The queries are `matching_domain_metadata.rs:858` and `:961`. Suspected cause: upstream Go schema (go/ submodule) differs from the schema the Rust struct was written for, or the struct needs `Option<Vec<u8>>`. Not fixed here. The MySQL and PostgreSQL lanes pass, so only the Cassandra UDT mapping is affected. Not confirmed locally.
Runs: 46108484364, 46116777632, 46108518236, 46108520323, 46108522461, 46108524783.

Matches the known todo in memory (refresh stale rust/Cargo.lock). Latest Cargo.lock/Cargo.toml changes: `d263b752a`, `22da380e0`, `ec5319079`. Fix is to regenerate and commit `rust/Cargo.lock`.
