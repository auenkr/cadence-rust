## Step 2: Rust trace
- Transfer queue notify/poll (`transfer_queue_processor_base.rs`): `notify_new_task` wakes the pump immediately; same as Go. No deviation.
- Deviation found: `launcher.rs matching_resolver` called `endpoint_channel` (new `connect_lazy` channel) on every
  AddDecisionTask/AddActivityTask, so each call opened a fresh TCP + HTTP/2 connection (handshake + SETTINGS exchange,
  delayed-ACK exposure) and dropped it. Go (yarpc) keeps a pooled connection per peer.
- Fix: cache one lazy `Channel` per Matching gRPC address in the resolver (cloned per call, reconnects on failure).
