## Root causes
1. **Harness break (fixed): History swap/soak/restartgate.** Since 00965a22d the Rust Frontend defaults to gRPC outbound and takes ports from `CADENCE_HISTORY_GRPC_PORT` / `CADENCE_MATCHING_GRPC_PORT`. Only run-frontend-gate.py / run-frontend-soak.py were updated; run-history-{swap,soak,restartgate}.py did not pass them, so the Frontend dialed default ports (`tcp connect error` to 127.0.0.1:15941). Fix: `fix-sweep-history-gates` ecc0cb1a5 (3 files, +2 lines each). Result: History swap green x3 (45235823325, 45235830935, 45235836703).
2. **Real Rust bug (NOT fixed): Frontend gRPC outbound uses ONE history gRPC port for every History host.** `grpc_outbound.rs::grpc_address(addr, self.history_port)` rewrites any History TChannel address to the single configured gRPC port (env `CADENCE_HISTORY_GRPC_PORT`/config). Go resolves the per-member `grpc` ring label (`membership.PortGRPC`; Rust Matching already does this in matching_history_membership.rs). With two History hosts on one machine (gates) the second host is dialed on host 1's gRPC port: it answers `ShardOwnershipLost owner=<host2>`, the Frontend redirects to the same wrong port, loops until the deadline; workflows stay at query state "init". Evidence: restartgate artifact (run 45238260766) frontend log full of `gRPC outbound cadence-history/RespondDecisionTaskCompleted ... ShardOwnershipLost(owner 127.0.0.1:14525)` repeated; 774 started, 133 completed. The same applies to the History soak (two_history default true) and two-History mixed gate. Only gates with 2 History hosts fail; single-host lanes are green. Suggested fix: Frontend resolves History gRPC address from the ring member's `grpc` label (fallback to configured port), and ShardOwnershipLost owner redirect uses the same mapping. Needs a Frontend change plus rust-ci -p cadence-frontend, then rerun soak/restart/two-history mixed.
3. Mixed gate two-History failures (45220173084, 45220188739) match cause 2 (both ran ~80 min and failed all SDK starts); 45220188739 rerun was queued; not separately verified.
