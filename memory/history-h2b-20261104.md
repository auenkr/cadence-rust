# History H2b progress (2026-11-04)

Branch: `history-h2b-tchannel-shards`, based on `origin/master`.

## Implemented

- Added a dedicated History TChannel listener using the existing shared TChannel v2/Thrift decoder. History binds the History service RPC port (`rpc.port`, default 7934) and accepts only `HistoryService` and `Meta` procedures on the `cadence-history` service identity.
- The dispatcher keeps History RPCs explicitly registered via the pinned Thrift service definition and returns `HistoryService::<method> is not implemented yet` until an engine implementation exists. Existing Thrift codec path is reused.
- Added shard reconciliation over all configured shard IDs, periodic acquisition ticker, immediate membership-snapshot updates, local shard close on ownership change, and shutdown cleanup. `ShardStore` remains the CAS persistence contract used by the in-memory fake; the controller requires no concrete SQL implementation.
- Added unit coverage for membership reconciliation and closing shards whose ownership changes. Existing tests cover ownership stealing and Go-compatible redirect address.

- `ShardOwnershipLost` currently uses the existing shard error representation. Exact Go Thrift application-error serialization for this error needs a TChannel wire oracle and remains to be verified.
