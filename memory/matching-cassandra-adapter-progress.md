Cassandra task rows multiplex task and task-list rows in the `tasks` table, partitioned by `(domain_id, task_list_name, task_list_type)`. Row `type=0` is a task; `type=1, task_id=-12345` is the task-list lease. Go task UDT fields are `domain_id`, `workflow_id`, `run_id`, `schedule_id`, `created_time`, and `partition_config`. The task-list UDT fields are `domain_id`, `name`, `type`, `ack_level`, `kind`, `last_updated`, and `adaptive_partition_config`; the latter includes nested read/write partition maps in current schema. Go batches task inserts with a conditional range-id update, so any Rust implementation must preserve the logged conditional batch atomicity and TTL behavior.

Go domain lookup reads `domains_by_name_v2` (partition 0) for the nested `domain`, `config`, and `replication_config` UDTs and notification/version columns; it also relies on `domains` for the UUID-to-domain mapping. The domain config UDT includes retention, emit metrics, archival settings, bad binaries, isolation groups, and async workflow config blobs/encodings. Replication includes active cluster, clusters, and active-cluster config blobs.

The `CassandraBlockingSession` source addition owns a dedicated multi-thread Tokio runtime for Scylla and schedules runtime destruction on a plain helper thread so its final drop can safely originate from a Tokio worker. Its drop/timer regression is source-only and has not been built or run. No Cargo build, lockfile update, database test, or service run was performed; all changes need validation in the coordinated build lane before they establish parity.

Source-only audit addendum (2026-10-20; still unvalidated):

- `nosqlTaskStore.CreateTasks` computes `Expiry - currentTimeStamp` in whole seconds, drops rows whose nonzero expiry is already reached, and gives each accepted row the same fresh `CreatedTime`; `CDB.InsertTasks` omits TTL for nonpositive values and caps positive values at `630720000`. The Cassandra adapter's expiry filtering, TTL second truncation, and cap match Go. It now receives the queue operation timestamp explicitly, so empty batches and re-added rows use the same `CurrentTimeStamp` for task-list fencing, row `CreatedTime`, and TTL calculation. Source-only assertions cover rounding and expired rows; runtime checks remain pending.
- Rust `task_list_lwt_applied` now uses Scylla 1.9's dynamic `scylla::value::Row` decoder and reads the first `[applied]` value, independent of returned current-row columns. Runtime behavior remains unvalidated against Cassandra.
- Domain enumeration now passes opaque driver paging state and requested page size through Scylla `query_single_page`, preserving Go Cassandra page token interoperability. Add a live mixed seed test for the `cadence-domain-metadata` sentinel at page boundaries.
- Panic/error robustness: unsupported `DateTime` nanosecond ranges now return an explicit configuration error, and task read limits use checked `i32` conversion. Cassandra range GC now follows Go's single range DELETE contract; it runs a count first to preserve the Rust interface, so the reported count can race concurrent changes.
- `tests/run-matching-cassandra-interop.py` is a runnable focused Go-seed → Rust lease/write/reconnect/read → Go-verify harness. It requires the existing Go schema and records per-phase commands/logs/exits, but was not run by instruction. It does not establish service-level parity.
