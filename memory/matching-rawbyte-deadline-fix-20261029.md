Constraints, variant overrides, flexible-rollout stickiness and variant hashing use those bytes; existing JSON/string provider API remains available. Numeric/date/semver invalid-byte input fails parsing. The Go SDK strategy and variant hash inputs are group, colon and raw stickiness bytes (murmur3 seeds 0 and 86028157).

Negative durations stay immediate. Go duration arithmetic and dispatch timeout computation remain unchanged.
