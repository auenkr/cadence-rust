Verdict

Where Rust wins

  • CPU: 18–47% less in every lane (History 0.56×, All 40/s 0.53×).
  • Memory: 12–39% less RSS (Matching 0.62×).
  • p99 lower in every lane (0.88–0.94× at 25/s).
  • At 40/s Go p99 is 1158 ms; Rust stays at 107 ms.
  • 13–16% fewer MySQL queries when History is Rust.

Where Go is close

  • No lane where Go is better on p50, p99, CPU or memory.
  • Matching p50: Rust 33.6 vs Go 34.4 ms (0.98×, noise).
  • Matching / Frontend MySQL load: identical (1.00×).
  • Matching CPU gap is the smallest (0.82×).

Throughput

  • At 25/s both keep up (≈25 compl/s).
  • At 40/s: Rust 39.95/s, Go 39.77/s on the accepted run; on 5 other runners the Go arm could not sustain 40 starts/s and timed out.
