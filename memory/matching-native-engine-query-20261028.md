# Native Matching engine query scope (2026-10-28)

`matching_engine_query_native.rs` is an unregistered private child of `matching_engine_native.rs`. It implements queue selection, sticky poller check, UUID query registration, raw native payload dispatch, local worker result/version handling and typed error propagation, forwarding and partition response configuration. The checked context supplies domain name, queue ownership, forwarding degree, parent routing and missing-deadline policy. The existing native decision poll path calls retrying native History GetMutableState and delivers its errors through the query channel; History owns sticky-to-normal retry, not Matching's QueryWorkflow. Parent must wire both methods, checked admission/ownership and a byte-preserving parent RPC/error transport before use.

Limitations: like the existing grpc implementation, exhausted forwarding permits force a local-only wait instead of Go's race between a newly available permit and a local poller; the native channel's buffered offer also does not fully reproduce Go's unbuffered rendezvous. The parent must resolve these semantics before claiming exact parity. Context deadline fallback follows the existing grpc policy and must be aligned with the actual transport. Parent forwarding uses a fresh request and returns typed raw errors, but no concrete transport implementation is provided here. Focused tests exercise raw payload/ID and cancellation with the real registry index; they have not been run. No Cargo, Go, rustfmt, CI, staging, commit or push was performed.
