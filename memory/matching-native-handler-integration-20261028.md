# Native Matching handler pieces, 2026-10-28

Scope: added `rust/crates/cadence-matching/src/matching_handler_native.rs` only, without registering the module or changing the launcher. It provides byte-preserving task-list identifier errors, API kind and partition-config mapping, query completion mapper validation and engine-wide delivery, poller cancellation on an already loaded queue, and update/refresh validation and calls into the native registry. The caller must wrap native transport with `RawStatusService` for raw identifier errors.

This is not a `NativeMatchingApi` implementation and is not ready to register as the service. Missing work includes all 13 RPC entry points; startup/shutdown, panic capture, quota, metrics, domain lookup and ownership checks in their exact Go order; poll/add/query forwarding, deadlines and cancellation; describe/list/domain enumeration; semaphore; and native adapters for configuration, membership, domain cache, persistence and history. The helpers assume the caller has performed required admission/domain/ownership checks, and the queue and key refer to the same manager. Query mapper validation must run before side effects; failure metrics on delivery remain the caller's responsibility. The scaler check must precede update validation. Registry APIs are concurrently changing and must be reconciled before integration. Do not route native requests through the UTF-8 handler.

Validation: source inspection only. No Cargo, rustfmt, Go build/test, CI, or mixed-cluster validation was run; the module has not been compiled or tested. No parity or completion claim is made.
