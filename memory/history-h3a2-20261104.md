## Implemented in `rust/crates/cadence-history/src/mutable_state.rs`

- Added a history-local `DecisionInfo` record, pending/in-flight lookups,
  decision update/delete/fail transitions, and basic schedule/start event
  creation with contiguous event IDs.
- Added the activity ID to scheduled-event index, activity schedule tracking,
  and activity deletion cleanup using local `Record` values.
- Added Rust unit cases for decision pending/start/fail and activity index
  creation/deletion.

These methods are initial state primitives, not a complete method-by-method
port of the named Go files. No persistence crate files were changed.

## Gaps

- The complete decision manager behavior is still absent: transient task
  scheduling and replication, heartbeat scheduling/sticky-list behavior,
  schedule-to-start/reset timeouts, completed/failed/timed-out replication,
  reset points, decision task queues, task generation, and workflow execution
  cache/version/history side effects.
- Activity behavior remains largely absent: typed `ActivityInfo`, schedule and
  start replication semantics, started/completed/failed/timed-out/cancel
  requested/canceled transitions, request-cancel failure, retry/backoff and
  timer task status, heartbeat progress, task generation, and consistency
  errors/logging.
- The Go manager and builder tests have not been ported; only the two focused
  Rust primitive tests above were added. Full Go parity cannot be claimed.
- `Record` and mutation/snapshot persistence contracts remain provisional and
  local to cadence-history, as required to avoid the active persistence branch.
