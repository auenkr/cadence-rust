# History H3A2 decision/activity progress — 2026-11-04

Branch: `history-h3a2-decision-activity`

## Current status

The requested CI failure was traced to decision fields used by the current
mutable-state skeleton but missing from `MutableStateBuilder`, and a wrong
`TaskList` import. This change adds the decision/activity fields, includes both
in `WorkflowMutation`, fixes the import, and adds tests for decision state
round-tripping and mutation serialization.

## Ported methods

- `MutableStateBuilder::decision_snapshot`: reconstructs persisted decision
  metadata, including sticky task-list selection.
- `MutableStateBuilder::persist_decision`: copies decision metadata to the
  workflow execution record.
- `MutableStateBuilder::delete_decision_preserving_heartbeat`: clears decision
  metadata while retaining the original scheduled timestamp.
- Existing skeleton methods retained: pending/in-flight checks, schedule/start,
  decision failure attempt increment, and decision/activity persistence.

## Gaps

The Go files `mutable_state_decision_task_manager.go`,
`mutable_state_builder_methods_decision.go`, and
`mutable_state_decision_task_manager_test.go` are not fully ported. In
particular, replication transitions and task generation; completed, failed,
and timed-out event handling; reset and schedule-to-start timeout behavior;
transient decision events; workflow mutability validation; checksum/reset
point handling; and the Go manager test cases remain. The Rust crate currently
does not expose the Go manager's shard, task-generator, clock, metrics, logger,
or full mutable-state builder dependencies. Activity behavior is explicitly
out of scope for this branch's decision task.
