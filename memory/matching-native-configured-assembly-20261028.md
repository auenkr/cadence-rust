# Native configured assembly seam — 2026-10-28

Matching remains incomplete and production continues to use the legacy durable registry. `assemble_configured` constructs a byte-store registry from the already limited configured task store, History client, production cache and live state, with the native writer and reader fatal adapters feeding the launcher's fatal channel. It installs registry metrics and a real poll observer, membership/parent routing and partition refresh, and the native scaler starter. It passes the already limited native semaphore store, quota, parse policy, cache and shutdown state to the native host. It creates an in-memory runtime with no legacy durable queue owner. Semaphore context timeout reporting resolves the cache and uses the Matching metric sink and inbound metadata.

The Go `service/matching/service.go` starts the resource before the handler; handler startup starts the engine/executor and only then releases the startup gate. Stop evicts membership, waits the configured drain, then stops the handler and resource; engine stop stops the executor, managers and semaphore buckets. The existing native runtime is intended to own those transitions. No activation is performed here.

Integration contract and blockers:

- The configured launcher must replace, not supplement, its `ConfiguredDefaultStore` durable runtime with this helper, passing `stores.native_task_store` and the previously opened `_native_semaphore_store`, both already wrapped with the same limiter as metadata. It must use the actual production membership, quota, metrics and fatal sender, then continue configuring runtime watchers, executor, listener startup and shutdown. Never attach it to the legacy durable runtime.
- `NativeLocalPollServiceBuilder` is currently infallible and cannot return absence when the host has not yet been published or has stopped. It must become a weak, fallible service attachment (or equivalent) which upgrades only for each dispatch and retains `NativeLocalPollHost::registry()` liveness without an ownership cycle. The assembly explicitly requires this provider and does not fake it.
- `ScalerMetrics` receives only `ScalerObservation`, with no queue/domain context; a correct per-task-list Go scaler metric provider cannot be built from it. Extend its factory/callback to carry the root queue metric context, then supply the real scoped sink. `PollObserverFactory` also lacks task-list kind, although metric context includes it; the caller must supply the correct observer after that contract is fixed. No no-op callbacks are supplied.
- Native runtime ownership, async shard lookup, late router, admission and startup failure/drain semantics need integration with the other workers' changes before activation. The registry/scaler read their shared late router where implemented. Verify the real listener selects the native service for both transports.
- Added source regressions for observer sink/context and native fatal conversion through the launcher with raw SQL RunID bytes. Existing host tests exercise the startup gate, but these additions do not establish configured startup, admission, storage/limiter or service parity. Add end-to-end configured-store and failure/recovery tests during integration.
